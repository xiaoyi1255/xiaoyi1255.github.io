### 一、命令式与生命式
`命令式`：命令式编程关注的是“怎么做”，它指定了具体的步骤和流程，更接近计算机的执行过程
```js
const div = document.querySelector('#app')
div.innerHTML = 'hello world'
div.addEventListener('click', () => { console.log('click') })
```
`声明式`： 声明式编程则关注“做什么”，描述了结果，而实现细节由系统处理。
```html
<div @click="() =>  console.log('click')" id="app">hello word</div>
```
#### 区别：
命令式更关注过程，声明式更关注结果

更新性能差异

命令式：直接操作原生，更优 ===> A

### 二、虚拟DOM的性能
页面更新：
`innerHTML`：重新构建 `html` 字符串, 在重新设置DOM原生的innerHTML属性；只修改了一个文字，也需要重新执行。等价于全量销毁所有旧DOM，再全量创建新的DOM

`虚拟DOM`：重新构建JavaScript对象（虚拟DOM树），然后对比新旧虚拟DOM树（DOM Diff）,然后找到变化的元素并更新它

`原生JavaScript`: 找到变化的元素，更新它（维护成本高，，页面大了更难维护），页面大了复杂了，虚拟DOM的优势就展示出来了

innerHTML（模板）	虚拟DOM	原生JavaScript
心智负担中等	心智负担小	心智负担大
性能差	可维护性强、性能不错	可维护性差、性能高
